# Codex Security Findings Board

이 파일은 총괄 대화만 수정한다. 앱별 대화는 자기 finding 파일에 기록하고, 총괄 대화가 이 보드로 취합한다.

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| 신규 | 아직 총괄 검토 전 |
| 검토 중 | 중복 제거와 우선순위 검토 중 |
| 승인 | 수정 대상으로 승인됨 |
| 진행 중 | 담당 대화가 수정 중 |
| 수정 완료 | 수정과 기본 검증 완료 |
| 오탐 | 보안 문제가 아닌 것으로 판단 |
| 보류 | 제품/정책 결정 필요 |
| 이관 | 다른 담당 대화로 넘김 |

## 우선순위 정의

| 우선순위 | 기준 |
| --- | --- |
| Critical | 인증/권한 우회, 결제/정산 변조, 타인 개인정보 접근 |
| High | role/store/driver 소유권 검증 누락, webhook 검증 누락 |
| Medium | 민감 정보 cache, 과도한 공개 조회, 방어 로깅 부족 |
| Low | 보안 문서/테스트 보강, 낮은 영향의 hardening |

## 통합 보드

| ID | 우선순위 | 상태 | 담당 | 영역 | 요약 | 증거 | 수정 대상 | 검증 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

## 1. 내비게이션 구조 결정

### 결정: **하단 탭 3개** (쿠팡이츠 배달원 패턴)

| 탭 | 경로 | 배지 |
|----|------|------|
| 작업 보드 | `/board` | 수거 대기 건수 (빨간 배지) |
| 지도 | `/map` | - |
| 내 정보 | `/profile` | - |

**결정 근거**:
- 드라이버 앱은 **탐색이 아닌 태스크 완료 중심** — 소비자·판매자 앱의 5탭 구조 불필요
- **쿠팡이츠 배달원·배민라이더스 모두 핵심 탭을 3~4개로 최소화** — 운전 전후 즉시 조작 가능
- **정산 탭 MVP 제외 결정**: MVP 드라이버 = 판매자 겸 드라이버. 수익 정산은 판매자 앱 정산 탭과 중복이며, 외부 드라이버 고용 시(Phase 2) 추가.
- 한 손 조작 + 야외 가독성 우선 → 하단 집중, 탭 최소화

## 2. 사이트맵 (Sitemap)

### Main Navigation (하단 탭 3개)

```
├── 작업 보드 (Board)              ← 기본 진입 화면
│     수거 대기 탭 (PREPARING)
│     배송 중 탭 (DELIVERING)
│
├── 지도 (Map)
│     전체 배송지 멀티 마커 + 추천 방문 순서
│
└── 내 정보 (Profile)
      계정 정보(카카오 연동), 로그아웃
```

### Sub Screens (상세 및 기능 화면)

```
├── 로그인 (/login)                ← 미로그인 시 전체 리다이렉트
│     카카오 OAuth 단일 경로 (이메일 로그인 미지원)
│     role 'seller' | 'driver' 허용 (middleware)
│
├── 배송 상세 (/board/[orderId])
│     [수거 전] 주문 정보, 수거 완료 버튼, 연락처
│     [배송 중 - 직배송] 배송 완료 버튼, 연락처
│     [배송 중 - 거점] 거점 도착 버튼, 연락처
│
└── 거점 하차 인증 사진 (/board/[orderId]/photo)   ← 풀스크린 전용
      카메라 실행, 촬영 확인, 업로드 후 HUB_ARRIVED 전환
```

## 3. 사용자 이동 경로 (User Flow)

### A. 로그인

```
앱 최초 접근 또는 미로그인 상태
    ↓
로그인 화면 (/login)
  - 카카오로 로그인 버튼 (단일 경로)
  - middleware: role 'seller' | 'driver' 검증
    ↓
→ 작업 보드 (/board)로 이동
```

### B. 직배송 주문 처리 (메인 플로우)

```
작업 보드 — 수거 대기 탭
  - Firestore 실시간 리스너로 PREPARING 주문 자동 수신
  - 카드 정렬: preparedAt 오름차순 (수거 예정 빠른 순)
    ↓
주문 카드 클릭 → 배송 상세 (/board/[orderId])
  - 배송 유형 뱃지: [직배송]
  - 소비자명, 배송지 주소, 상품명·수량, 수거 예정 시간
  - 연락처 바로가기 (판매자 전화번호 → tel: 딥링크)
    ↓
[수거 완료 / 배송 시작] 버튼 클릭
  - PATCH /orders/:orderId/status { status: 'DELIVERING' }
  - driverId 자동 기록 (서버에서 session.userId 저장)
  - 소비자에게 카카오 알림톡 자동 발송 "배송이 시작되었습니다"
    ↓
→ 배송 중 탭으로 주문 이동
→ 지도 탭에서 카카오내비 딥링크로 주행 가능
    ↓
배송 상세 (배송 중 상태)
  - 연락처 바로가기 (소비자 전화번호 → tel: 딥링크)
    ↓
[배송 완료] 버튼 클릭
  - PATCH /orders/:orderId/status { status: 'DELIVERED' }
  - 소비자에게 알림톡 "배송이 완료되었습니다"
    ↓
→ 배송 완료. 작업 보드에서 해당 주문 사라짐
```

### C. 거점 픽업 주문 처리

```
... B 플로우의 수거 완료까지 동일 ...
    ↓
배송 상세 (배송 중 — 거점 주문)
  - 배송 유형 뱃지: [거점 픽업]
  - 거점명 + 거점 주소 표시
    ↓
[거점 도착] 버튼 클릭
  - 하차 인증 사진 화면으로 이동 (/board/[orderId]/photo)
    ↓
거점 하차 인증 사진 화면 (풀스크린)
  - 카메라 실행 (MediaDevices API)
  - 사진 촬영 → 미리보기 확인
  - [재촬영] 또는 [업로드] 선택
  - 업로드: Firebase Storage → deliveryPhotos/{orderId}_{timestamp}.jpg
    ↓
업로드 완료
  - PATCH /orders/:orderId/status { status: 'HUB_ARRIVED', photoUrl: string }
  - 소비자에게 알림톡 "거점에 도착했습니다. 픽업 코드: XXXXXX"
    ↓
→ 작업 보드에서 해당 주문 사라짐
```

### D. 다중 배송지 경로 최적화

```
지도 탭 (/map)
  - 오늘 수거 대기 + 배송 중 주문의 배송지 전체 마커 표시
  - Nearest Neighbor 알고리즘 기반 추천 방문 순서 번호 마커
    ↓
[주행 시작] 버튼 클릭
  - kakaomap://route?ep={lat},{lng}&via=... 딥링크 호출
  - 카카오내비 앱 자동 실행 (미설치 시 스토어 연결)
    ↓
운행 중 → 각 배송지 도착 시 배송 상세에서 상태 전환
```

## 4. 상세 화면별 주요 구성 요소

### 1. 로그인 (/login)

```
중앙: Green Hub 로고
하단: [카카오로 시작하기] 버튼 (카카오 노란색 스타일)
      ※ 이메일/네이버 로그인 없음 (드라이버 앱 전용 정책)
```

### 2. 작업 보드 — 수거 대기 탭 (/board?tab=preparing)

```
상단: "오늘 배송" 제목 + 날짜 표시
      [수거 대기 N건] [배송 중 M건] 탭 전환
중단: 주문 카드 목록 (preparedAt 오름차순)
  ┌── 주문 카드
  │   ├── 배송 유형 뱃지: [직배송] / [거점 픽업] / [택배]
  │   ├── 소비자명
  │   ├── 배송지 주소 (거점 픽업 시 거점명 + 주소)
  │   ├── 수거 예정 시간 (preparedAt — 미설정 시 "시간 미정")
  │   └── 상품명 · 수량
  └──
빈 상태: "오늘 수거할 주문이 없습니다" + 지도 탭 유도
```

### 3. 작업 보드 — 배송 중 탭 (/board?tab=delivering)

```
상단: 탭 전환 (수거 대기 / 배송 중)
중단: DELIVERING 상태 주문 카드 목록
  ┌── 주문 카드
  │   ├── 배송 유형 뱃지
  │   ├── 소비자명 + 배송지 주소
  │   └── 배송 시작 시각
  └──
빈 상태: "현재 배송 중인 주문이 없습니다"
```

### 4. 배송 상세 — 수거 전 (/board/[orderId], status=PREPARING)

```
상단: ← 뒤로가기 / 배송 유형 뱃지
중단:
  [주문 정보 섹션]
    - 상품명 · 수량
    - 판매자 수거 위치 (판매자 주소)
    - 배송지 주소
    - 수거 예정 시간 (preparedAt)
    - 거점 픽업: 거점명 + 거점 주소 추가 표시

  [연락처 섹션]
    - 판매자 연락처 + [전화] 버튼 (tel: 딥링크)

하단: [수거 완료 / 배송 시작] 버튼 (56px 이상, 전폭)
      ※ 탭 누르기 쉬운 하단 고정
```

### 5. 배송 상세 — 배송 중, 직배송 (/board/[orderId], status=DELIVERING, method=direct)

```
상단: ← 뒤로가기 / [직배송] 뱃지 + "배송 중" 표시
중단:
  [배송 정보 섹션]
    - 소비자명
    - 배송지 주소 (지도 미니 뷰 — 카카오맵 Static Map)

  [연락처 섹션]
    - 소비자 연락처 + [전화] 버튼 (tel: 딥링크)

하단: [배송 완료] 버튼 (56px 이상, 전폭, 초록색)
```

### 6. 배송 상세 — 배송 중, 거점 픽업 (/board/[orderId], status=DELIVERING, method=hub)

```
상단: ← 뒤로가기 / [거점 픽업] 뱃지 + "배송 중" 표시
중단:
  [거점 정보 섹션]
    - 거점명 + 거점 주소
    - 지도 미니 뷰

  [연락처 섹션]
    - 판매자 연락처 + [전화] 버튼 (소비자 정보 미노출 — 개인정보 보호)

하단: [거점 도착] 버튼 (56px 이상, 전폭, 파란색)
      클릭 → /board/[orderId]/photo 이동
```

### 7. 거점 하차 인증 사진 (/board/[orderId]/photo)

```
상단: ← 뒤로가기 (취소) + "거점 하차 인증 사진" 제목
중단: 카메라 뷰파인더 (풀스크린)
      ※ 미리보기 확인 화면으로 전환 가능
        [재촬영] / [업로드] 버튼

업로드 중: 스피너 + "업로드 중..." (버튼 비활성)
업로드 완료: 자동으로 HUB_ARRIVED 상태 전환 → 보드로 복귀
실패 시: "업로드 실패. 다시 시도해주세요" 토스트 + 재시도 버튼
```

### 8. 지도 (/map)

```
상단: "오늘 배송 경로" 제목 + 주문 건수
중단: 카카오맵 Web SDK 지도
  - PREPARING + DELIVERING 주문 배송지 마커 (추천 방문 순서 번호)
  - 직배송: 소비자 주소 마커
  - 거점 픽업: 거점 주소 마커
  - 경유지 연결 폴리라인 (Should Have)

하단 고정 패널:
  - 경유지 목록 (추천 순서별 주소 리스트)
  [주행 시작] 버튼 → 카카오내비 딥링크
  ※ 주문이 없을 때: "오늘 배송 주문이 없습니다" 빈 지도

다크 모드: prefers-color-scheme: dark 자동 감지 (Tailwind dark: 클래스)
```

### 9. 내 정보 (/profile)

```
상단: 카카오 프로필 이미지 + 이름
중단:
  - 연결된 계정: 카카오 (OOO@kakao)
  - 앱 버전 정보

하단: [로그아웃] 버튼
```

## 5. 상태 전환 버튼 노출 조건 매핑

| 화면 | 조건 | 노출 버튼 | API 전환 |
|------|------|----------|----------|
| 배송 상세 | status=PREPARING | [수거 완료 / 배송 시작] | PREPARING → DELIVERING |
| 배송 상세 | status=DELIVERING, method=direct | [배송 완료] | DELIVERING → DELIVERED |
| 배송 상세 | status=DELIVERING, method=hub | [거점 도착] | → /photo 화면 이동 |
| 인증 사진 화면 | 사진 업로드 완료 | [업로드 완료 처리] | DELIVERING → HUB_ARRIVED (photoUrl 포함) |
| 배송 상세 | status=DELIVERING, method=parcel | 없음 (택배는 드라이버 앱 상태 전환 없음) | — |

> **택배 주문**: 드라이버가 택배사에 인계한 시점부터 드라이버 앱의 역할은 종료. DELIVERED 전환은 판매자 앱 또는 택배사 연동 Webhook이 처리 (MVP: 판매자 앱에서 수동 전환).

## 6. Consumer 앱 연동 결정 사항

### 거점 도착 인증 사진 소비자 노출 여부 결정

> 드라이버 1단계 요구사항에서 "선택적 노출 — IA에서 결정"으로 남겨둔 항목

**결정: 노출** — HUB_ARRIVED 이후 소비자 앱 주문 상세에 "거점 도착 사진" 섹션 표시

**근거**:
- 소비자 입장에서 "내 주문이 거점에 잘 도착했는지" 확인 욕구가 있음
- 픽업 전까지 상품 훼손 분쟁 예방 효과 (드라이버 도착 시점 증빙)
- 구현 비용: `deliveryPhotoUrl` 필드가 이미 존재하므로 consumer 주문 상세에서 조건부 렌더링만 추가

**노출 방식**: 주문 상세 하단, `status >= HUB_ARRIVED` 조건에서만 표시

## 7. 벤치마킹 참조 가이드

| 앱 | 참고 패턴 |
|----|----------|
| 쿠팡이츠 배달원 | 하단 탭 최소화, 단계별 큰 버튼 CTA, 운행 중 지도 연동 |
| 배민라이더스 | 수거 대기 / 배달 중 탭 분리, 배달 완료 액션 플로우 |
| 카카오내비 | 딥링크 파라미터 구조 (`kakaomap://route?ep=`) |

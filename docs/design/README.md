# Design 문서 라우팅

> 이 디렉터리의 `1단계-요구사항`, `2단계-IA`, `배송-추가검토사항` 문서는 초기 제품 설계 과정의 역사 자료다.

현재 화면·도메인 계약의 정본으로 직접 사용하지 않는다. 이후 회차 직배송 MVP, 인증, 결제, 정산, 배송 보류·재배송, admin 기능이 크게 확장되었기 때문이다.

## 현재 작업 시 우선순위

1. 현재 `main` 코드
2. 직접 관련 `docs/specs/` 현행 명세
3. `packages/shared` 공개 타입
4. `docs/CRITICAL_LOGIC.md`의 관련 결정
5. 이 디렉터리의 초기 요구사항·IA

이 디렉터리의 문서를 근거로 현재 기능을 삭제·복원하거나 과거 TODO를 재개하지 않는다.

## 사용 가치

- 초기 사용자 문제와 UX 의도를 추적할 때
- 현재 UI가 왜 특정 구조로 시작했는지 확인할 때
- 회귀나 설계 방향 변경의 배경을 확인할 때

새 요구사항을 추가할 때는 이 초기 문서에 계속 덧붙이지 말고 현재 domain/frontend spec 또는 새 Task 문서에 기록한다.

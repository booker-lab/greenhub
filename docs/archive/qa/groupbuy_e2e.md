## TC-1. Seller: 공동구매 상품 등록 ✅

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | Seller → 상품 관리 → `+등록` | 상품 등록 폼 진입 |
| 2 | 판매 방식 → `공동구매` 선택 | 공동구매 설정 섹션 슬라이드 다운 |
| 3 | 최소 인원: `2`, 최대 인원: `3` 입력 | 정상 입력 |
| 4 | 모집 마감일시: **현재 시각 기준 5분 후** (datetime-local) | 시간 포함 입력 가능 확인 |
| 5 | 배송 예정일: 마감일 다음 날 | 날짜 선택 |
| 6 | 배송 수단: `꽃차 직배송` | 선택 |
| 7 | 나머지 필드 입력 후 `등록하기` | 상품 등록 완료, 목록 이동 |

## TC-2. Consumer: 상품 상세 — 공동구매 정보 표시 ✅

| 5 | 동의 체크박스 미체크 상태 | `바로 결제` 버튼 비활성화 |

## TC-5. 선착순 마감 — maxParticipants 도달 시 조기 확정 ✅

> maxParticipants=2로 설정한 상품 기준 (계정 부족으로 동일 계정 2회 결제로 검증)

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | 2번째 결제 (maxParticipants 도달) | 결제 완료 |
| 2 | 약 10~30초 후 주문 상태 확인 | RECRUITING → **CONFIRMED** 자동 전환 |
| 3 | Consumer 마이페이지 | 주문 상태 **"주문 확정"** |
| 4 | Seller 주문 목록 | CONFIRMED 주문 → `준비 시작` 버튼 활성화 |

**비고**: 중복 참여 방지 로직 추가됨 (같은 계정 재구매 시 409)

## TC-6. 인원 미달 — 마감 후 자동 취소 ✅

> 마감 2~3분짜리 별도 상품 사용

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | 1명만 참여 후 마감 대기 | |
| 2 | 마감일시 + 약 1분 후 | 주문 상태 **RECRUITING → CANCELLED** |
| 3 | Consumer 마이페이지 | 주문 상태 **"주문 취소"**, cancelReason: "목표 수량 미달성으로 취소" |

**비고**: `isProcessed: false` 필드 누락 버그 발견·수정 (코드 반영 완료)

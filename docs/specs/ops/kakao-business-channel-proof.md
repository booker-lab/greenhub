# 카카오 비즈니스 채널 홈페이지 증빙 기록

> **상태**: 완료된 외부 심사 증거 문서
> **현재 판정**: 카카오 비즈니스 채널 최종 승인 완료
> **현재 작업 지시 여부**: 아님
> **최종 정합화**: 2026-08-23 KST

## 1. 문서 목적

이 문서는 카카오 비즈니스 채널 심사 과정에서 홈페이지의 운영 주체·사업자 고지·법적 문서를 보강했던 배경을 보존한다.

과거 재반려·재신청 대기 상태는 더 이상 현재 상태가 아니다. 현재 출시 판단에서 카카오 비즈니스 채널 승인을 차단 요인으로 사용하지 않는다. 현재 외부 차단 요인은 `docs/memory.md`와 활성 HANDOFF·PLAN을 따른다.

## 2. 완료된 결과

- 그린러브 홈페이지에서 운영 주체와 사업자 고지를 확인할 수 있도록 공개 정보를 정리했다.
- 개인정보처리방침과 이용약관을 비로그인 공개 경로로 제공했다.
- 공개 판매상품과 시험용 데이터의 노출 경계를 보강했다.
- 홈페이지 및 관련 증빙을 기반으로 카카오 비즈니스 채널 심사를 진행했다.
- 이후 카카오 비즈니스 채널은 최종 승인됐다.

따라서 이 파일의 과거 “추가 재신청 금지”, “문의 답변 대기”, “반려 상태” 절차를 다시 실행하지 않는다.

## 3. 현재 정본 위치

공개 사업자 정보 값을 이 문서에 중복 복제하지 않는다. 현재 값을 확인하거나 변경할 때는 다음 정본을 사용한다.

- 공개 사업자 정보 코드: `apps/consumer/src/lib/publicBusinessInfo.ts`
- 소비자 법적 문안: `docs/specs/legal/consumer-legal-documents.md`
- 홈페이지: `apps/consumer`
- 현재 제품·외부 심사 상태: `docs/memory.md`
- 배포 URL: `docs/URLS.md`를 확인한 뒤 필요 시 실제 운영 환경 재검증

사업자등록증 원본, 개인 계정 정보, 비공개 전달 주소, 인증정보와 같은 원문은 Git 문서에 복제하지 않는다.

## 4. 유지되는 공개 계약

### 사업자·법적 고지

- 홈페이지 footer는 서비스 운영 주체를 식별할 수 있는 공개 사업자 정보를 제공한다.
- 개인정보처리방침과 이용약관은 비로그인 상태에서 접근 가능해야 한다.
- 법적 문안은 서비스의 실제 판매·주문·결제 상태와 모순되지 않아야 한다.
- 모바일에서도 footer·법적 링크가 고정 내비게이션에 가려지지 않아야 한다.

### 공개 상품 경계

- 공개 상품 목록은 실제 공개 대상으로 판정된 활성 상품만 노출한다.
- 시험용 데이터는 실제 소비자 판매 목록에 노출하지 않는다.
- 비활성 또는 시험용 상품 상세를 공개 경로에서 우회 조회할 수 있게 만들지 않는다.
- 실제 상품의 가격·재고·활성 여부는 운영 판단 없이 문서 정합화 작업이 임의 변경하지 않는다.

## 5. 역사적 심사 설명

카카오 심사 과정에서는 홈페이지에서 채널과 사업자의 관계, 실제 판매 서비스, 필수 고지를 함께 확인할 수 있어야 한다는 요구를 충족하기 위해 홈페이지 증빙을 강화했다.

이 과정의 세부 반려 문구·당시 외부 상태·당시 배포 SHA는 역사 자료이며 현재 재신청 절차가 아니다. 필요한 경우 Git history와 당시 PLAN·REPORT를 조회한다.

## 6. 변경·승인 경계

이 문서는 외부 운영 변경 권한을 부여하지 않는다.

다음 작업은 필요할 경우 별도 사용자 승인 후 수행한다.

- 카카오 채널 정보 변경
- 카카오 재심사·추가 신청
- 운영 홈페이지 사업자 정보 변경
- production 배포
- 운영 데이터·환경 변수 변경

현재 채널 승인은 완료 상태이므로, 회차 직배송 출시의 다음 외부 게이트는 카카오 채널 심사가 아니라 `docs/memory.md`의 ALIGO 템플릿 심사 상태를 따른다.

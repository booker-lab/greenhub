## 확인된 범위

- 사용자가 제시한 사업자등록증과 확인 내용에 따라 사업자명은 `디어오키드`, 대표자는 `조정연`으로 확정됐다.
- 공개 브랜드명과 카카오 채널명은 `그린러브`다.
- 사용자가 `그린러브는 디어오키드가 운영하는 화훼 판매 브랜드입니다.`라는 운영 관계 문구의 공개를 승인했다.
- 공개 홈페이지 URL은 `https://greenlove.co.kr/`이다.
- 네이버 플레이스는 현재 없으므로 홈페이지에 관련 링크를 노출하지 않는다.
- 통신판매업 신고번호는 현재 없으므로 홈페이지에 해당 번호를 노출하지 않는다.
- 등록 사업장 주소는 실제 집주소이며 사용자가 공개에 동의하지 않았다. 전체 주소는 코드·문서·REPORT에 기록하지 않는다.
- 사용자가 변경된 사업자등록증을 제시해 사업장 소재지 정정 처리가 완료된 사실은 확인했다.
- 사용자가 변경 사업자등록증의 최종 사업장 주소를 확인했지만 공개에 동의하지 않았으므로 값은 기록하지 않고 공개 정본에서 제외한다.
- 별도 개통한 공개 고객센터 번호 `010-4452-2104`를 사용자가 홈페이지 공개 용도로 제공했다. 이 번호를 공식 정본 후보로 채택한다.
- 공개 고객센터 이메일은 `support@greenlove.co.kr`로 확정됐다.
- ImprovMX의 `greenlove.co.kr` 도메인 상태가 Active이고 `support@greenlove.co.kr` 별칭이 생성됐다.
- 공개 DNS에서 `mx1.improvmx.com` 우선순위 10, `mx2.improvmx.com` 우선순위 20과 SPF `v=spf1 include:spf.improvmx.com ~all`이 확인됐다.
- 테스트 메일이 `support@greenlove.co.kr`로 접수되어 비공개 운영 Gmail 서버에 `DELIVERED`된 사실을 확인했다.
- 기존 홈페이지 A/CNAME과 서비스 응답은 유지됐다.
- 비공개 전달 Gmail 주소, 계정 로그인 이메일, 사업자등록증 원본 이미지, 생년월일은 저장소·REPORT·PR에 첨부하거나 복사하지 않는다.

# 어드민 콘솔 모바일 반응형 — 육안 검증 체크리스트

> 작성: 2026-05-25 (세션88) · 출처: [#CL-51] 5개 테이블 카드형 전환 · 플랜 [admin-responsive-plan.md](admin-responsive-plan.md)
> 성격: 코드·빌드 정합성(C1~C6)은 종결. 본 문서는 **모바일 폭 카드 레이아웃 육안 확인**(환경 제약상 사용자 영역).

## 검증 환경

- **계정**: 어드민 권한 계정(role=admin) 카카오 로그인. 운영 단일 DB(green-e4fe3).
- **폭 전환 기준**: breakpoint `sm` = **768px**. 768px 미만=카드, 이상=테이블.
- **방법**: 브라우저 DevTools 디바이스 툴바(폭 ≤480px 권장) 또는 실기기 PWA.
- **데스크톱 대조**: ≥768px(노트북 풀폭)에서 기존 테이블 그대로인지 동시 확인.

---

## A. 모바일(<768px) — 카드형 노출·버튼 접근 (핵심 결함 해소)

- [ ] **#1 정산(`/admin/settlements`)** — 카드 노출. 각 카드: 스토어ID·상태 Badge·정산일시·거래/수수료·지급액 표시.
- [ ] **#2 정산 — `confirmed` 상태 카드에 [지급처리] 버튼 노출·탭 가능** (← 원래 결함, 최우선).
- [ ] **#3 정산 — `confirmed` 외 상태 카드엔 지급처리 버튼 미노출**(기존 로직 유지).
- [ ] **#4 주문(`/admin/orders`)** — 카드 노출. 주문번호·상태 Badge·스토어·금액 표시.
- [ ] **#5 주문 — 환불 가능 상태(ACCEPTED/RECRUITING/CONFIRMED/PREPARING) 카드에 [강제환불] 버튼 노출·동작**.
- [ ] **#6 스토어(`/admin/stores`)** — 카드 노출. 상호·ID·상태 Badge·수수료율·[수수료 설정] 버튼 표시.
- [ ] **#7 스토어 — [수수료 설정] 탭 → 인라인 입력+[저장]/[취소] 정상 동작**(편집 폼 카드 내 표시).
- [ ] **#8 초대(`/admin/invite`)** — 발급내역 카드 노출. 토큰·상태 Badge(유효/사용됨/만료)·만료일 표시.
- [ ] **#9 사용자(`/admin/users`)** — 카드 노출. 이름·이메일·상태 Badge·[정지]/[복구] 버튼 표시.
- [ ] **#10 사용자 — [정지]/[복구] 탭 → ConfirmModal 정상 표출·처리**.

## B. 모바일 — 레이아웃 품질

- [ ] **#11 5개 화면 모두 가로 스크롤 발생 0** (카드가 폭 안에 수납).
- [ ] **#12 긴 텍스트(이메일·토큰) 줄바꿈/말줄임 정상** — 카드 밖 넘침 0.
- [ ] **#13 빈 결과("정산 내역이 없습니다" 등) 메시지 정상 표시**(카드 분기에서도 깨지지 않음).
- [ ] **#14 로딩("불러오는 중...") 표시 정상**.

## C. 데스크톱(≥768px) — 회귀 0 (DOM 불변이라 안전, 확인용)

- [ ] **#15 5개 화면 모두 기존 테이블 레이아웃 그대로** — 컬럼·정렬·여백·Badge 위치 변화 0.
- [ ] **#16 데스크톱에서 카드가 보이지 않음**(`hiddenFrom="sm"` 정상 동작).
- [ ] **#17 모바일에서 테이블이 보이지 않음**(`visibleFrom="sm"` 정상 동작).

## D. 전환 경계

- [ ] **#18 폭을 768px 전후로 리사이즈 시 카드↔테이블 전환이 자연스럽고 깜빡임/중복 노출 없음**.

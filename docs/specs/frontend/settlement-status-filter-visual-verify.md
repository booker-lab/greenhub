## B. 버튼 크기 단일화 (세션87 #234 / #CL-50)

> 진입: 주문 목록(`/orders`) → "준비 시작" 가능한 주문 → 상세(`/orders/[id]`)
> 변경: 상세 footer 3버튼 `size="lg"`→`size="md"` (카드 `sm` 유지, radius·fullWidth 불변)
> 핵심: 카드→상세 이동 시 같은 "준비 시작" 버튼의 **크기 점프가 완화**(2단계→1단계 차)됐는지 눈으로 확인

> 목적: status 필터 UI 구현(T1~T3) 결과를 **브라우저에서 사람이 직접 눈으로** 확인.

## 검증 환경

| 항목 | 값 |
|------|-----|
| 진입 경로 | 정산 관리 → [주문별 상세] 탭 |
| 권장 뷰포트 | 모바일 PWA 폭 (≤480px) — 5탭 가로 스크롤 확인이 핵심이므로 **반드시 모바일 폭** |
| 로그인 | 운영은 카카오만 (환경 제약: `reference_visual_verify_env`) |
| 시드 | status별 데이터가 섞여 있어야 필터 효과 확인 가능 — `seed-settlements-visual` 등으로 pending/confirmed/paid/cancelled 혼합 시드 권장 |
| 비교 기준 | 리팩토링 전 화면 = status 탭 없이 CSV 버튼 + 목록만 |

## V. status 필터 UI

### V-T1 — 필터 탭 렌더 (5탭)

| # | 확인 항목 | 통과 기준 | 결과 | 메모 |
|---|----------|----------|:----:|------|
| 1 | [주문별 상세] 탭 진입 직후 | 목록 위에 status 탭 줄 노출 (`전체 / 정산 대기 / 확정 / 지급 완료 / 취소`) | [ ] | |
| 2 | 탭 라벨 문구 | shared SSOT `STATUS_LABEL`과 정확히 일치 (정산 대기·확정·지급 완료·취소) | [ ] | |
| 3 | 초기 진입 시 활성 탭 | **전체**가 선택(밑줄·primary 색) | [ ] | |
| 4 | 탭 5개 순서 | 전체 → 정산 대기 → 확정 → 지급 완료 → 취소 | [ ] | |

### V-T2 — 모바일 가로 스크롤 (C4 핵심)

| # | 확인 항목 | 통과 기준 | 결과 | 메모 |
|---|----------|----------|:----:|------|
| 5 | 모바일 폭(≤480px)에서 5탭 | 잘림·줄바꿈 없이 **가로 스크롤**로 모든 탭 접근 가능 | [ ] | |
| 6 | 스크롤바 | 막대 스크롤바 미노출(`scrollbarWidth:none`)이나 좌우 스와이프는 동작 | [ ] | |
| 7 | 마지막 탭(취소)까지 | 가로 스크롤 끝에서 잘리지 않고 전체 라벨 표시 | [ ] | |

### V-T3 — 탭 전환 → 필터 동작 (C2)

| # | 확인 항목 | 통과 기준 | 결과 | 메모 |
|---|----------|----------|:----:|------|
| 8 | **정산 대기** 탭 클릭 | 목록이 pending 건만 노출되도록 재조회 (네트워크 `?status=pending`) | [ ] | |
| 9 | **확정** 탭 클릭 | confirmed 건만 노출 (`?status=confirmed`) | [ ] | |
| 10 | **지급 완료** 탭 클릭 | paid 건만 노출 (`?status=paid`) | [ ] | |
| 11 | **취소** 탭 클릭 | cancelled 건만 노출 (`?status=cancelled`) | [ ] | |
| 12 | 탭 전환 중 | "불러오는 중..." 로딩 표시가 탭 **아래**에 노출되고, 탭 줄은 사라지지 않음 | [ ] | |

### V-T4 — 전체 탭 회귀 (C3)

| # | 확인 항목 | 통과 기준 | 결과 | 메모 |
|---|----------|----------|:----:|------|
| 13 | 다른 탭 → **전체** 복귀 | 모든 status 합산 목록으로 복귀 (status 미전달 = 기존 전체 조회와 동일) | [ ] | |
| 14 | 전체 탭 목록 내용 | 리팩토링 전 [주문별 상세] 전체 목록과 동일(회귀 0) | [ ] | |

### V-T5 — 빈 결과·CSV (C6)

| # | 확인 항목 | 통과 기준 | 결과 | 메모 |
|---|----------|----------|:----:|------|
| 15 | 해당 status 건이 0건인 탭 | "정산 완료된 주문이 없습니다" 메시지가 **탭 아래** 노출(탭 줄은 유지) | [ ] | |
| 16 | 빈 결과 상태에서 다른 탭 | 탭이 사라지지 않아 곧바로 다른 status로 전환 가능 | [ ] | |
| 17 | 목록 존재 시 CSV 다운로드 버튼 | 기존과 동일하게 목록 우상단 노출·동작 | [ ] | |

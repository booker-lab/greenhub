## 1. 체크 방법

1. 아래 진행판에서 가장 위에 남아 있는 `[ ]` 묶음부터 검증한다.
2. 원본 문서의 해당 번호를 열고 화면, 동작, 모바일 배치를 확인한다.
3. 원본 문서의 결과 칸에 판정을 기록한다.
   - 통과: `[x]`
   - 실패 또는 보완 필요: `[ ]` 유지 후 메모에 화면, URL, 재현 조건과 `visual-verify-fix-backlog.md` 작업 번호 기록
   - 계정 또는 데이터 부재로 확인 불가: `[-]` 후 사유 기록
4. 묶음의 일부만 처리했으면 확인 완료 범위와 잔여 범위를 분리해 각각 `[x]`, `[ ]`로 표시한다. 묶음 전체를 처리했으면 완료 기록에 한 줄을 추가한다.
5. 상태를 바꾸는 동작은 운영 데이터에서 바로 실행하지 않는다. 테스트 데이터 또는 롤백 가능한 데이터가 준비된 경우에만 진행한다.
6. 실패 또는 보완 필요 항목의 수정 내용은 `visual-verify-fix-backlog.md`에 누적하고, 순차 검증이 끝난 뒤 일괄 수정한다.

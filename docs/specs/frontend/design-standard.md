# 그린러브 디자인 기준

> 2026-10-03 사용자 확정. 파일럿(2026-11-01) 전 프런트 개편의 시각 계약이다.
> 값의 정본은 `packages/ui/src/styles/base.css`(공용 CSS 변수)와 `packages/ui/src/styles/tokens.css`(Tailwind·shadcn 의미 변수)이고(UI 교체 P6에서 `style.css`·`theme.ts`를 옮김), 이 문서는 각 값을 **어디에 쓰는지**를 정한다.
> 확정 시안: https://claude.ai/artifact/SGYHNJGqPpGQCT9BsVYYpG (소비자 홈·상품 상세·장바구니, 판매자 주문)

## 1. 방향

30~40대가 익숙한 쇼핑 앱 문법을 따르는 "프레시 그린"이다. 밝은 초록 면, 노란 마감 강조, 둥근 카드와 완전히 둥근 버튼, 굵기로 위계를 나누는 고딕 한 가지를 쓴다. 회차 직배송의 핵심(언제까지 주문하면 언제 오는지, 몇 개 남았는지)을 화면 위쪽과 상품 옆에 항상 보이게 한다.

### 2.1 다크 모드

2026-11-02 사용자 확정(`design-direction.md` §9.6 D5-a·D5-b·D5-c), 판매자·어드민·기사 앱 적용 완료(2026-11-03). **소비자 앱은 다크 모드를 쓰지 않고 밝은 화면만 쓴다**(2026-11-03 사용자 결정).

- **값의 정본**은 `packages/ui/src/styles/dark.css`다. 위 표의 어둠 값 열과 다른 의미 변수(`--background`·`--card`·`--popover`·`--ui-*` 등)를 이 파일만 다시 정의하고, 컴포넌트는 토큰만 읽는다. 하드코딩 색을 새로 넣지 않는다(`check-css-vars`).
- **바탕 단계**: 틀 `#0F1311`(`--frame`) → 종이 `#161B18`(`--background`·`--color-bg`) → 면 `#232A26`(`--color-surface-muted`) → 떠 있는 창 `#1E2421`(`--popover`). 그림자 대신 위쪽 1px 선(`--bar-shadow: 0 -1px 0 var(--rule)`)으로 고정 바를 나눈다.
- **초록**: 버튼 면 `--primary` `#007A43`과 흰 글자는 밝음과 같다. 초록 글자는 `#4FD08C`(`--color-primary-dark`·`--brand-ink`), 빨강 글자는 `#FF7366`, 채운 빨강 면은 `#D92D20`(흰 글자 4.8:1)이다.
- **기사 앱은 무채색**이다: 바탕 `#121212` · 카드 `#1C1C1C` · 면·떠 있는 메뉴 `#262626`, 글자 `#F2F2F2` · 보조 `#B0B0B0`. 표에 없는 자리도 같은 밝기의 무채색이다(확장 값, 2026-11-03 조정 세션 확정 안 A): 선 `#333333`(`--rule`·`--card-border`) · `#2A2A2A`(`--color-border`) · `#3D3D3D`(`--ui-gray-3`), 입력칸 테두리 `#6B6B6B`, 꺼진 글자 `#8E8E8E`, `--ui-gray-7` `#C8C8C8`, 고정 바는 위쪽 1px `--rule` 선. 대비 표는 `design-direction.md` §9.2 "기사 앱 확장 값"이다.
  - 기사 `apps/driver/src/app/globals.css`의 기사 전용 블록이 dark.css 뒤에서 회색 값만 덮어쓰고, 초록·빨강·노랑 값은 dark.css를 그대로 쓴다.
- **전환**: 기본은 기기 설정(`prefers-color-scheme`)을 따른다. 판매자 설정 "정보" 카드와 기사 내 정보 계정 카드의 한 줄 "화면 모드: 시스템 / 밝게 / 어둡게"(`@greenhub/ui` `ColorSchemeSetting`)로 직접 고를 수 있다. 선택 표시는 검정 2px 테두리·굵은 글자(초록 면 없음)이고, 라디오 그룹 이름이 "화면 모드"다.
  - 저장은 `localStorage` 키 `greenhub-color-scheme` 하나(값 `light`·`dark`, 시스템이면 키 없음)다. 값이 잘못됐거나 저장소를 쓸 수 없으면 시스템으로 본다. 쿠키는 쓰지 않는다.
  - 판매자·기사 루트 layout `<head>`의 고정 인라인 스크립트(`@greenhub/shared` `COLOR_SCHEME_SCRIPT`)가 첫 페인트 전에 `<html data-theme="light|dark">`을 넣고, CSP `script-src`는 그 sha256 해시로 허용한다(앱 CSP 구성 `inlineScriptHashes`, 소비자는 넣지 않는다). 스크립트를 바꾸면 해시도 바꾼다(`color-scheme.test.ts`).
  - CSS 선택자는 두 곳에 같은 값이다: `@media (prefers-color-scheme: dark)` 안 `:root:not([data-theme="light"])`와 `:root[data-theme="dark"]`. 기사 전용 블록도 같다. 두 블록이 같은지는 `scripts/ui/dark-css.spec.mjs`가 본다. `color-scheme`은 시스템이면 `light dark`, 고르면 그 값이다.
  - viewport `themeColor`는 기기 설정을 따르는 정적 메타 두 값(밝음 `#00A65A`, 어둠 판매자 `#0F1311`·기사 `#121212`)이다. 직접 고른 모드는 따르지 않고 그대로 둔다(2026-11-03 결정, #809). 밝은 기기에서 '어둡게'를 고르면 상태 표시줄·주소창 색만 밝게 남는다. 따르게 하려면 인라인 스크립트가 meta를 고쳐야 하고 해시도 바뀐다.
- **바꿀 수 없는 외부 화면**(어둠에서도 밝게 열린다): 카카오맵(기사 지도). 카카오 로그인 버튼의 노랑은 브랜드 규정 값으로 고정한다. 소비자 앱의 외부 화면(PortOne 결제창, 다음 우편번호 창, 카카오 채널 버튼)은 소비자가 밝은 화면만 쓰므로 해당하지 않는다(`design-direction.md` §9.4).
- **후속 후보**(사용자 결정 전에는 하지 않는다):
  - 어둠에서만 상품 사진 둘레에 흰 6% 안쪽 선(`design-direction.md` §9.1). 흰 배경 사진이 밝은 네모로 뜨는 것을 줄인다. 지금은 넣지 않았다.
  - 판매자·기사 `global-error.tsx`(루트 layout을 대신하는 최후 오류 화면)의 다크 모드. 전역 CSS 없이 인라인 색으로 그려 지금은 밝게 나온다.

## 3. 글자

- 글꼴은 **Pretendard** 한 가지(각 앱 `globals.css`가 self-hosting). 굵기 400·700·800으로 위계를 나눈다.
- 화면 제목·상세 상품명 22/800, 섹션 제목 18/800, 가격 16~24/800, 본문 15/400, 설명·태그 13/700.
- 글자 크기 토큰은 `--font-size-xs` 13 · `sm` 15 · `md` 16 · `lg` 18 · `xl` 20이다. Mantine `size="xs"`·`"sm"` 글자도 테마 `fontSizes`가 이 토큰을 따르므로 같은 크기다. 굵지 않은 설명 글씨는 15(`sm`)로 쓰고, 13(`xs`)은 굵은 태그·배지에만 쓴다.
- 가격·시간·수량은 `font-variant-numeric: tabular-nums`로 자리를 맞춘다. 마감 카운트다운 숫자는 흔들리지 않게 고정폭으로 표시한다.
- 앱별 `AGENTS.md`의 15px 최소 규칙 예외 목록은 그대로 유지한다.

## 4. 모양과 간격

- 모서리: 사진·카드 16(`--radius`), 태그 6(`--radius-tag`), 버튼·칩·수량 조절·검색창은 완전히 둥글게(`--radius-full`, Mantine Button 기본 `xl`).
- 그림자는 화면 아래 고정 바(소비자 하단 메뉴·판매자 하단 탭, `0 -4px 16px rgba(17,17,17,0.06)`)와 메뉴·대화상자처럼 실제로 떠 있는 것에만 쓴다. 사진 위 + 담기 버튼은 그림자 없는 흰 원이다(`design-direction.md` §3.1, 2026-11-02 적용). 나머지는 연한 선과 바탕색으로 구역을 나눈다.
- 간격은 4의 배수, 화면 좌우 여백 16, 터치 영역 최소 44(`--touch-target`).

## 5. 화면 구성 원칙

- **소비자 홈**: 흰 머리띠(흰 바탕에 초록 로고 글자 `--color-primary-dark`, 검정 알림·장바구니 아이콘, 연회색 `--color-surface-muted` 검색창, `design-direction.md` §2 2026-10-29 결정, 2026-11-02 적용) → 노란 마감 띠 → 분류 칩 → 회차 배너 → 도감 타일 그리드(`design-direction.md` §4.1·§8 D1, 2026-11-02 적용). 타일은 연회색(`--color-surface-muted`) 단색 면 위 4:5 사진(모서리 16)이고 테두리가 없다. 사진 위에 그림자 없는 흰 원 + 담기를 겹치고, 타일 밖 아래 왼쪽에 이름(15/700) → 가격(16/800, 남은 수량 1~5개면 같은 줄 오른쪽에 검정 굵은 "n개 남음") → 도감 라벨(13/700 회색 한 줄, 개화·꽃대·향·관리·높이·화분 지름·송이 수·빛·놓을 곳 중 있는 값) 순서다. 7개마다(첫 상품부터) 한 상품을 2칸 폭·한 행 높이(사진 8:5)로 키운다. 도착·판매 예정·판매 종료 태그는 없고, 품절과 열린 회차 안의 판매 종료 상품은 그리드 아래 한 줄 목록(작은 그림 · "품절 · 상품명 · 가격" · "다음 회차에 다시 올라와요")으로 모은다. 지난 회차는 그리드에 흐린 사진으로 둔다. 상품 탭 회차 목록도 같은 타일이고, 검색·예전 상품 카드(`ProductCard`)는 연회색 사진 타일·테두리 없음·도감 라벨만 맞추고 분류 칩·공구 진행 막대를 유지한다.
- **소비자 하단 메뉴**: 위쪽 1px 선 대신 고정 바 그림자(`0 -4px 16px rgba(17,17,17,0.06)`)로 본문과 나눈다. 현재 탭은 초록 없이 검정 아이콘(굵은 선)과 검정 굵은 글자로 표시한다(`design-direction.md` §3.1·§3.2).
- **상품 상세**: 흰 상단 바(뒤로·초록 로고·검정 홈·장바구니 아이콘, 아래 선 없음) → 큰 사진(연회색 면, 여러 장이면 사진 아래 점: 지금 사진 검정·나머지 회색, 점마다 높이 44px 버튼) → 회차 요약(상품명 30/800 → 18px 한 줄 "12월 1일(화) 문 앞 도착 · 경기도 이천시 직접 배송", 구매할 수 없을 때만 앞에 "품절"·"판매 마감"·"판매 예정 회차"를 굵게 붙인다 → "회차 가격" 24/800 → 배송 흐름 상자: 주문 마감 › 새벽 경매 › 문 앞 도착) → 상품 설명 → 필수 고지(경기 이천 직접배송·기상 연기·청약철회) → 수량 조절 → 하단 고정 바 한 줄: 외곽선 "장바구니"와 초록 면 주 버튼("39,000원 바로 구매", 살 수 있을 때 총 금액을 버튼 글자 앞에 넣는다). 하단 바는 위쪽 선 대신 고정 바 그림자다. 제목 위 상태 태그·회차 이름 라벨은 두지 않는다(`design-direction.md` §4.3, 2026-11-02 적용). 두 버튼 이름("장바구니", 이름에 "바로 구매" 포함)은 회차 E2E 계약이라 유지한다.
- **장바구니**: 마감 안내 상자(노랑 연한 바탕) → 상품 카드 → 금액 요약 상자 → 하단 고정 결제 버튼. 결제 화면의 주문 요약도 테두리 상자 대신 연회색 면이고, 결제 수단 선택 표시는 검정 2px 테두리·굵은 글자다(초록 면 없음, `design-direction.md` §3.2·§4.3, 2026-11-02 적용). 장바구니는 구성을 유지하고 "이번 주 판매" 상자를 연회색 면으로, 상품 카드는 테두리 없이 줄 사이 선으로 나눈 목록으로, "회차 가격" 태그는 연회색 면 + 검정 글자로, 서버 확인 표시는 점 + 글자(확인 중=회색, 확인 완료=검정)로 바꿨다. 로그인 화면의 주문 안내 상자와 개인정보 처리방침의 안내 상자도 연두 면·테두리 대신 연회색 면이다(2026-11-02 적용).
- **소비자 마이페이지**(MY·주문 상세·배송지·알림·알림 설정·찜·구매한 꽃): 메뉴 줄·주문 카드·배송지 카드·안내 상자는 테두리 상자 대신 연회색 면(`--color-surface-muted`, 모서리 16)이다. 프로필 머리도 연두 면 대신 연회색 면이다. 주문 상태는 배지 면 없이 점 + 글자(`packages/ui` `StatusDot`: 배송 보류=빨강, 취소·결제 확인 중·배송 완료·구매 확정=회색, 나머지 검정, 판매자 주문 상태와 같은 규칙)다. 알림은 안 읽음 줄의 연두 면을 걷고 굵은 글자와 검정 점으로 표시하며, 알림 아이콘 원은 문제=빨강 연한 면, 마감 임박=노랑 연한 면, 나머지=연회색 면 + 검정 아이콘이다. 배송지 "기본" 표시는 흰 태그 + 검정 굵은 글자, 재배송비 결제 수단 선택 표시는 검정 2px 테두리·굵은 글자다(2026-11-02 적용).
- **판매자·어드민 앱**(기사 앱은 아래): 같은 색·글꼴·부품을 쓰되 소비자 홈 머리띠는 쓰지 않는다. 판매자 틀(머리·하단 탭·탭 띠·페이지 바탕)은 `--frame` 한 색이고 머리 아래 선을 긋지 않는다(D3, 하단 탭은 §3.1 고정 바 그림자). 판매자 카드는 그림자와 바깥 1px 테두리 없이 틀 위 흰 면(`bg-white`, 모서리 16)으로만 구역을 나누고, 카드 안 목록 행 사이 선은 유지한다(D2). 판매자 홈의 금액·건수는 검정 굵은 글자이고, "오늘 할 일" 줄 앞 점은 문제=빨강, 나머지=검정이다(초록은 행동, 노랑은 마감에만). 회차 진행 중이면 노란 마감 띠, 요약 숫자는 연두 상자, 판매자 주문 상태는 배지 면·카드 왼쪽 색 띠 없이 점 + 글자(`packages/ui` `StatusDot`: 배송 보류=빨강, 취소·결제 대기·완료=회색, 나머지 검정)이고, 운영 기록 상태도 같은 규칙(문제=빨강, 끝남=회색)이다(2026-11-01 결정). 판매자 주문 목록의 검색·날짜·보조 필터 띠는 `--frame`이고 띠 사이 선이 없으며, 선택 칩은 흰 바탕 + 검정 1px 테두리 + 굵은 검정 글자, 일반·공구 전환은 검정 3px 밑줄이다. 우선순위 상자는 문제일 때 빨강 연한 면(테두리 없음), 아니면 `--frame` 면이다. 주문 상세의 강조 값은 초록 대신 검정이다. 판매 회차 목록·상세의 회차 상태와 마감 사유, 회차 폼의 비활성 상품 표시도 점 + 글자다(작성 중·배송 완료·취소·마감 사유·비활성=회색, 나머지 검정). 회차 폼 안 하위 카드(상품 줄·링크 줄)는 테두리 대신 `--frame` 면이고 입력칸 선은 유지한다. 준비 화면의 발송 지연 상자는 빨강 테두리 대신 빨강 연한 면이다. "이전 정보"를 보여 줄 때의 다시 조회 버튼은 노란 면 대신 중립 회색 외곽선(`outline-gray`)이다(2026-11-01 결정, 노랑은 마감에만). 상품 목록·상품 폼·옵션 재고 카드도 그림자 없는 흰 면이고, 상품 폼의 선택 버튼·색상 칩·공구 배송 수단의 선택 표시는 초록 면 대신 흰 바탕 + 검정 1px 테두리 + 굵은 검정 글자다(주문 선택 칩과 같은 규칙). 지금 단계 표시와 주요 버튼(다음·등록)은 초록을 유지한다. 정산 상태(목록·일별 요약)도 점 + 글자(지급 완료·취소=회색, 나머지 검정, 어드민 정산과 같은 규칙)이고 정산 예정 금액은 검정 굵은 글자다. 운영 확인의 열린 긴급 기록은 빨강 테두리 대신 빨강 연한 면, 해결 메모는 `--frame` 면이다. 숨긴 후기 카드는 `--frame` 면이고 숨김 표시는 회색 점 + 글자다. 홈 상태 카드의 다시 조회 버튼도 `outline-gray`다. 설정·거점·입구(로그인·로그인 오류·초대·사업자 프로필) 카드도 그림자 없는 흰 면이고, 거점 상태는 점 + 글자(운영 중·픽업 대기=검정, 비활성=회색)다.
- **어드민 위험 동작 확인창**(강제환불·배송 후 환불·정산 지급 기록·기사 승인·정지·정지 풀기·소비자 정지·초대 취소·판매자 정리하기·복구, `apps/seller/src/app/admin/_components/AdminConfirmDialog.tsx`, `design-direction.md` §5 어드민·§8 D7): 하나의 틀(`packages/ui` `DialogContent`)을 쓴다. 제목은 동작 + 대상("주문 20261128-000014 환불", "이대기 님을 기사로 승인")이고, 대상 정보와 돈의 흐름은 연한 회색 이름–값 상자(줄 구분선은 상자 안쪽 전체 폭)다. 되돌릴 수 없으면 확정 버튼 위에 빨간 한 줄을 쓴다. 강제환불은 "되돌릴 수 없음을 확인했습니다", 지급 기록은 "이체를 마쳤습니다" 체크를 비운 채 열고, 체크(배송 후 환불은 사유·메모) 전에는 확정이 꺼져 있다. 꺼진 확정 버튼 위에는 켜는 방법을 쓴다. 버튼은 닫기(회색 외곽선)와 초록 `#007A43` 확정 하나이고, 위험도와 상관없이 빨간 채움 버튼은 쓰지 않는다(2026-11-01 적용). 휴대폰 아래 시트는 아직 적용하지 않았다(가운데 창, 버튼만 전체 폭으로 쌓음).
- **기사 앱**("한 손 배송 목록", `design-direction.md` §6·§8 D4, 2026-11-03 적용): 틀은 흰 바탕·검정 글자이고 색은 초록 주요 버튼과 문제 상태(빨강)에만 쓴다. 본문은 `--color-text`(18.9:1), 보조 글자도 15px `--driver-text-muted`(9.7:1)다. 배송판 머리는 로고 + "배송 목록" 한 줄, 배송지 점 띠(배송 중 검정·보류 빨강·내 수거 빈 원, 아무도 맡지 않은 주문은 그리지 않음), 15px 진행 줄("남은 배송 n곳 · 보류 n곳 · 수거 n곳 · 맡을 수 있는 n곳")이고 머리 아래 선이 없다(2026-11-10 #841·2차 배치). 탭 선택은 검정 3px 밑줄·굵은 검정 글자. 배송 중 탭의 첫 배송지(보류 제외)는 연회색 면의 "다음 배송지"(기본 주소 15 + 동·호수 28/800, 상품 20/700, 받는 분)이고 나머지는 두 줄 행(주소 16/700, 받는 분·상품 15)과 행 사이 선, 6곳째부터 "남은 n곳 더 보기"다. 수거 대기 탭은 "내 수거"·"맡을 수 있는 주문" 두 묶음이고 첫 화면 5행은 두 묶음을 합쳐 센다(내 수거가 먼저). 오늘이 아닌 회차 주문 행에는 "11월 10일(화) 배송"처럼 배송일을 쓴다. 주문 상세는 동·호수 h1(28/800, 나눌 수 없으면 전체 주소 20/800) → 상품 20/700 → 받는 분 → 요청사항(연회색 면) → 전화·길 찾기(`--driver-action-surface` 면·검정 글자, 나란히) → "배송 못 함 · 보류하기" 글자 버튼(배송 보류 창) 순서이고, 보류 내용·오류 안내는 빨강 연한 면 + 검정 글자, 재배송비 상태는 점 + 글자다. 주요 행동은 하나만 하단 바 위에 고정(높이 56px·전체 폭, AppButton `xl`, 위쪽 고정 바 그림자)하고 이름에 끝내는 동작을 쓴다("도착 사진 찍고 완료"). 손님에게 알림이 가고 되돌릴 수 없는 배송 시작·재개는 주소·상품 수·알림 사실을 보이는 확인 창을 거친다. 하단 바는 3칸이고 위쪽 선 대신 고정 바 그림자, 현재 탭은 검정 아이콘·굵은 검정 글자다. 동·호수는 전체 주소에서 기본 주소를 뺀 값(`lib/address-parts.ts`)이고, 기사 API에 없는 값(끝낸 배송 수·소요 시간·마감까지 남은 시간·경로 순번·상품 사진)은 쓰지 않는다. 회차 배송일은 기사 목록 API가 싣는 `deliveryDate`로만 쓴다.
- 예전 판매(legacy·공동구매) 화면은 토큰 변경만 따라가고 구성은 바꾸지 않는다.

## 6. 적용 순서

1. 공용 토큰·테마(이 문서와 같은 변경)
2. 소비자 회차 구매 동선: 홈 → 상품 상세 → 장바구니 → 결제 → 주문 완료 → 내 주문
3. 판매자 회차 운영 화면과 어드민(어드민은 넓은 레이아웃으로 분리)
4. 기사 배송 화면

각 단계는 로컬 화면 확인 장치(`feat/visual-harness`, 병합 후 `scripts/visual/`)로 찍은 개편 전 기준선과 비교해 검수한다.

## 7. 로고와 앱 아이콘

- 로고는 영문 **"Green Love"** 글자만 쓴다(잎·기호 없음). 글꼴은 **Nunito ExtraBold(800)**, 화면에서는 `--font-brand`로 쓰고 각 앱이 라틴 글자만 담은 `public/fonts/Nunito-ExtraBold-latin.woff2`(16KB)를 불러온다. 한글은 Pretendard로 넘어간다.
- 로고 원본 SVG(글자를 경로로 바꾼 것)는 `packages/ui/brand/greenlove-logo.svg`(짙은 초록)·`greenlove-logo-white.svg`(흰색)다.
- 앱 아이콘 상징은 **두 잎 하트**(잎 두 장이 만나 하트). 소비자=초록 바탕 상징만, 판매자=짙은 초록 바탕 상징+"Seller", 기사=검정 바탕 초록 상징+"Driver". 원본은 `packages/ui/brand/icon-*.svg`, 각 앱 `public/icons/icon-192x192.png`·`icon-512x512.png`와 `src/app/favicon.ico`는 이 SVG에서 렌더링했다.
- 사진 없는 상품의 대체 그림은 연한 회색 바탕에 옅은 상징(`apps/consumer/public/images/product-placeholder.png`, 원본 `packages/ui/brand/product-placeholder.svg`)이다.
- 아이콘 상징은 임시안이다. 다시 디자인할 예정이다(BACKLOG `BRAND-APP-ICON-REDESIGN`).

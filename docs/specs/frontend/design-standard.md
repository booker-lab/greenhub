# 그린러브 디자인 기준

> 2026-10-03 사용자 확정. 파일럿(2026-11-01) 전 프런트 개편의 시각 계약이다.
> 값의 정본은 `packages/ui/src/style.css`(CSS 변수)와 `packages/ui/src/theme.ts`(Mantine 테마)이고, 이 문서는 각 값을 **어디에 쓰는지**를 정한다.
> 확정 시안: https://claude.ai/artifact/SGYHNJGqPpGQCT9BsVYYpG (소비자 홈·상품 상세·장바구니, 판매자 주문)

## 1. 방향

30~40대가 익숙한 쇼핑 앱 문법을 따르는 "프레시 그린"이다. 밝은 초록 면, 노란 마감 강조, 둥근 카드와 완전히 둥근 버튼, 굵기로 위계를 나누는 고딕 한 가지를 쓴다. 회차 직배송의 핵심(언제까지 주문하면 언제 오는지, 몇 개 남았는지)을 화면 위쪽과 상품 옆에 항상 보이게 한다.

- 빨강은 문제 상태에만 쓴다. 할인·강조 용도로 쓰지 않는다.

## 3. 글자

- 글꼴은 **Pretendard** 한 가지(각 앱 `globals.css`가 self-hosting). 굵기 400·700·800으로 위계를 나눈다.
- 화면 제목·상세 상품명 22/800, 섹션 제목 18/800, 가격 16~24/800, 본문 15/400, 설명·태그 13/700.
- 글자 크기 토큰은 `--font-size-xs` 13 · `sm` 15 · `md` 16 · `lg` 18 · `xl` 20이다. Mantine `size="xs"`·`"sm"` 글자도 테마 `fontSizes`가 이 토큰을 따르므로 같은 크기다. 굵지 않은 설명 글씨는 15(`sm`)로 쓰고, 13(`xs`)은 굵은 태그·배지에만 쓴다.
- 가격·시간·수량은 `font-variant-numeric: tabular-nums`로 자리를 맞춘다. 마감 카운트다운 숫자는 흔들리지 않게 고정폭으로 표시한다.
- 앱별 `AGENTS.md`의 15px 최소 규칙 예외 목록은 그대로 유지한다.

## 4. 모양과 간격

- 모서리: 사진·카드 16(`--radius`), 태그 6(`--radius-tag`), 버튼·칩·수량 조절·검색창은 완전히 둥글게(`--radius-full`, Mantine Button 기본 `xl`).
- 그림자는 사진 위에 겹친 + 담기 버튼에만 쓴다. 나머지는 연한 선과 바탕색으로 구역을 나눈다.
- 간격은 4의 배수, 화면 좌우 여백 16, 터치 영역 최소 44(`--touch-target`).

## 5. 화면 구성 원칙

- **소비자 홈**: 초록 머리띠(로고·알림·장바구니·검색창) → 노란 마감 띠 → 분류 칩 → 회차 배너 → 2열 상품 그리드(사진 위 + 담기, 이름, 가격, 도착/남은 수량 태그).
- **상품 상세**: 큰 사진 → 회차 요약(상태 태그·회차 이름, 상품명, "회차 가격", 배송 흐름 상자: 주문 마감 › 새벽 경매 › 문 앞 도착) → 상품 설명 → 필수 고지(경기 이천 직접배송·기상 연기·청약철회) → 수량 조절 → 하단 고정 총 금액과 "장바구니"(외곽선)·"바로 구매"(초록 면) 두 버튼. 두 버튼 이름은 회차 E2E 계약이라 유지한다.
- **장바구니**: 마감 안내 상자(노랑 연한 바탕) → 상품 카드 → 금액 요약 상자 → 하단 고정 결제 버튼.
- **판매자·어드민·기사 앱**: 같은 색·글꼴·부품을 쓰되 초록 머리띠는 쓰지 않는다. 판매자 틀(머리·하단 탭·탭 띠·페이지 바탕)은 `--frame` 한 색이고 머리 아래 선을 긋지 않는다(D3, 하단 탭은 §3.1 고정 바 그림자). 판매자 카드는 그림자와 바깥 1px 테두리 없이 틀 위 흰 면(`bg-white`, 모서리 16)으로만 구역을 나누고, 카드 안 목록 행 사이 선은 유지한다(D2). 판매자 홈의 금액·건수는 검정 굵은 글자이고, "오늘 할 일" 줄 앞 점은 문제=빨강, 나머지=검정이다(초록은 행동, 노랑은 마감에만). 회차 진행 중이면 노란 마감 띠, 요약 숫자는 연두 상자, 판매자 주문 상태는 배지 면·카드 왼쪽 색 띠 없이 점 + 글자(`packages/ui` `StatusDot`: 배송 보류=빨강, 취소·결제 대기·완료=회색, 나머지 검정)이고, 운영 기록 상태도 같은 규칙(문제=빨강, 끝남=회색)이다(2026-11-01 결정). 판매자 주문 목록의 검색·날짜·보조 필터 띠는 `--frame`이고 띠 사이 선이 없으며, 선택 칩은 흰 바탕 + 검정 1px 테두리 + 굵은 검정 글자, 일반·공구 전환은 검정 3px 밑줄이다. 우선순위 상자는 문제일 때 빨강 연한 면(테두리 없음), 아니면 `--frame` 면이다. 주문 상세의 강조 값은 초록 대신 검정이다. 판매 회차 목록·상세의 회차 상태와 마감 사유, 회차 폼의 비활성 상품 표시도 점 + 글자다(작성 중·배송 완료·취소·마감 사유·비활성=회색, 나머지 검정). 회차 폼 안 하위 카드(상품 줄·링크 줄)는 테두리 대신 `--frame` 면이고 입력칸 선은 유지한다. 준비 화면의 발송 지연 상자는 빨강 테두리 대신 빨강 연한 면이다. "이전 정보"를 보여 줄 때의 다시 조회 버튼은 노란 면 대신 중립 회색 외곽선(`outline-gray`)이다(2026-11-01 결정, 노랑은 마감에만). 설정·거점·입구(로그인·로그인 오류·초대·사업자 프로필) 카드도 그림자 없는 흰 면이고, 거점 상태는 점 + 글자(운영 중·픽업 대기=검정, 비활성=회색)다.
- **어드민 위험 동작 확인창**(강제환불·배송 후 환불·정산 지급 기록·기사 승인·정지·정지 풀기·소비자 정지·초대 취소·판매자 정리하기·복구, `apps/seller/src/app/admin/_components/AdminConfirmDialog.tsx`, `design-direction.md` §5 어드민·§8 D7): 하나의 틀(`packages/ui` `DialogContent`)을 쓴다. 제목은 동작 + 대상("주문 20261128-000014 환불", "이대기 님을 기사로 승인")이고, 대상 정보와 돈의 흐름은 연한 회색 이름–값 상자(줄 구분선은 상자 안쪽 전체 폭)다. 되돌릴 수 없으면 확정 버튼 위에 빨간 한 줄을 쓴다. 강제환불은 "되돌릴 수 없음을 확인했습니다", 지급 기록은 "이체를 마쳤습니다" 체크를 비운 채 열고, 체크(배송 후 환불은 사유·메모) 전에는 확정이 꺼져 있다. 꺼진 확정 버튼 위에는 켜는 방법을 쓴다. 버튼은 닫기(회색 외곽선)와 초록 `#007A43` 확정 하나이고, 위험도와 상관없이 빨간 채움 버튼은 쓰지 않는다(2026-11-01 적용). 휴대폰 아래 시트는 아직 적용하지 않았다(가운데 창, 버튼만 전체 폭으로 쌓음).
- 예전 판매(legacy·공동구매) 화면은 토큰 변경만 따라가고 구성은 바꾸지 않는다.

## 6. 적용 순서

1. 공용 토큰·테마(이 문서와 같은 변경)
2. 소비자 회차 구매 동선: 홈 → 상품 상세 → 장바구니 → 결제 → 주문 완료 → 내 주문
3. 판매자 회차 운영 화면과 어드민(어드민은 넓은 레이아웃으로 분리)
4. 기사 배송 화면

각 단계는 로컬 화면 확인 장치(`feat/visual-harness`, 병합 후 `scripts/visual/`)로 찍은 개편 전 기준선과 비교해 검수한다.

## 7. 로고와 앱 아이콘

- 로고는 영문 **"Green Love"** 글자만 쓴다(잎·기호 없음). 글꼴은 **Nunito ExtraBold(800)**, 화면에서는 `--font-brand`로 쓰고 각 앱이 라틴 글자만 담은 `public/fonts/Nunito-ExtraBold-latin.woff2`(16KB)를 불러온다. 한글은 Pretendard로 넘어간다.
- 로고 원본 SVG(글자를 경로로 바꾼 것)는 `packages/ui/brand/greenlove-logo.svg`(짙은 초록)·`greenlove-logo-white.svg`(흰색)다.
- 앱 아이콘 상징은 **두 잎 하트**(잎 두 장이 만나 하트). 소비자=초록 바탕 상징만, 판매자=짙은 초록 바탕 상징+"Seller", 기사=검정 바탕 초록 상징+"Driver". 원본은 `packages/ui/brand/icon-*.svg`, 각 앱 `public/icons/icon-192x192.png`·`icon-512x512.png`와 `src/app/favicon.ico`는 이 SVG에서 렌더링했다.
- 사진 없는 상품의 대체 그림은 연한 회색 바탕에 옅은 상징(`apps/consumer/public/images/product-placeholder.png`, 원본 `packages/ui/brand/product-placeholder.svg`)이다.
- 아이콘 상징은 임시안이다. 다시 디자인할 예정이다(BACKLOG `BRAND-APP-ICON-REDESIGN`).

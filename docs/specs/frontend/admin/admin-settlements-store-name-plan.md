# 관리자 정산 스토어명 표시·선택 필터 SDD

> **작성일**: 2026-06-03
> **상태**: 설계 확정
> **출처**: `admin-tab-settlements-plan.md` F4, `BACKLOG.md` `ADMIN-SETTLEMENTS-F4`
> **범위**: `/admin/settlements` 스토어 필터와 정산 목록의 스토어 식별 정보

## 1. 목표

관리자가 정산 목록에서 스토어를 사람이 읽을 수 있는 이름으로 식별하고, 스토어명 검색으로 정산 범위를 좁힌다.

**기존 정산 조회 API의 `storeId` 필터 계약은 유지하고, 관리자 스토어 목록 조회를 화면 표시용 사전으로 재사용한다.**

## 2. 조회 계약

- 정산 조회는 기존 `GET /admin/settlements?storeId=`를 유지한다.
- 표시용 스토어 목록은 기존 `GET /admin/stores`를 `useAdminStores()`로 조회한다.
- 필터 UI는 검색 가능한 Mantine `Select`를 사용한다.
- Select의 사용자 표시값은 스토어명, 서버 전달값은 `store.id`다.
- 목록에 없는 과거 또는 고아 `storeId`는 축약 ID로 대체 표시한다.

## 3. 표시 계약

| 위치 | 표시 |
|------|------|
| 필터 | `전체 스토어` + 스토어명 목록 |
| 데스크톱 표 | 스토어명 우선, 누락 시 축약 ID |
| 모바일 카드 | 스토어명 우선, 누락 시 축약 ID |
| 선택 체크박스 접근성 이름 | 화면에 표시한 스토어 식별값 + `정산 선택` |

## 4. 비범위

- 정산 API 응답에 스토어명 중복 삽입
- 경량 전용 스토어 조회 API 추가
- 정산 500건 하드캡 페이지네이션
- 스토어 보관 상태별 필터 분기

## 5. 검증

- 스토어 Select에서 이름을 검색하고 선택하면 정산 조회 URL에 정확한 `storeId`가 전달된다.
- 데스크톱 표와 모바일 카드가 스토어명을 표시한다.
- 목록에 없는 스토어는 축약 ID로 대체 표시한다.
- 모바일 카드에서 가로 넘침이 없다.
- seller 타입체크, 변경 파일 Biome, seller 빌드를 통과한다.

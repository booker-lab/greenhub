# M-PATH — 셀러앱 리팩토링 전체(A~F) 마스터 통합 육안 검증 동선 (세션82 신설)

> 작성: 2026-05-23 (세션82 종료 후) · **다음 세션 = 이 M-PATH 한 번으로 셀러앱 리팩토링 전부를 육안 확정.**
> **통합 대상**: A 홈 대시보드(세션39) · B 주문 탭(세션42~45) · C 소비자 배송일(세션46~49) · D 셀러 주문 IA(세션50) · E 정산 탭(SETTLE-REFACTOR S1~S6) · F 셀러 UX 잔여(세션54~59).
> **목적**: 위 A~F 섹션·기존 F-VISUAL-PATH(V0~V10)에 흩어진 항목을 **로그인 1회 동선**으로 묶어 화면 이동을 최소화하고, 무엇을 사람 눈으로 보고 무엇이 이미 자동검증으로 닫혔는지 한눈에 구분.
> **사용법**: M0부터 순서대로. 각 화면 진입 시 그 구간 표를 다 본 뒤 다음으로. 결과 표기 `[x]` 통과 / `[ ]` 실패(메모) / `[-]` 해당없음. 세부 통과 기준은 각 행 "원본" 열의 연번(예: A-T1 #1)을 원 섹션에서 참조.
> **자동검증 갈음**: F-T-UX4(fontSize 토큰화)·회귀 grep·E 정산 백엔드 전이는 이미 정적/스크립트로 닫힘 → M-PATH에서는 **시각적으로 티 나는 항목만** 추리고, 나머지는 각 원 섹션의 ✅ 표기로 갈음(중복 육안 불필요).

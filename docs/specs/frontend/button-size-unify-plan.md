# 주문 "준비 시작" 버튼 크기 단일화 아토믹 플랜

> 작성: 2026-05-25 (세션86) · 출처: BACKLOG §1-3 `[UI-버튼크기]` (세션83 M-PATH #234 육안 발견)
> 성격: **독립 세션 1건**으로 완결되는 소 규모. **단, 단일화 여부는 설계 판단 — 착수 전 사용자 확정 필수.**

---

## 1. 문제 정의 (정합성 검토 실측)

동일 액션 "준비 시작" 버튼이 위치마다 크기가 2단계 다르다. 사용자가 카드→상세 이동 시 같은 버튼이 갑자기 커져 시각 괴리감을 느낀다.

### 실측 근거 (세션86)

| 위치 | size | radius | 근거 |
|------|------|--------|------|
| 목록 카드 | `sm` | `md` | [OrderCard.tsx:78-79](../../../apps/seller/src/app/orders/_components/OrderCard.tsx#L78) |
| 상세 footer | `lg` | `xl` | [page.tsx:165-166](../../../apps/seller/src/app/orders/[id]/page.tsx#L165) |

상세 footer에는 "택배 발송 완료"·"강제 취소" 버튼도 동일하게 `lg`/`xl`로 묶여 있다([page.tsx:175-198](../../../apps/seller/src/app/orders/[id]/page.tsx#L175)) — footer는 **풀폭 주 CTA 묶음**으로 의도된 위계로 보인다.

---

## 2. 설계 판단 — 단일화 여부 (착수 전 사용자 확정 필수)

이 항목은 **버그가 아니라 위계 설계 결정**이다. 두 해석이 가능:

| 해석 | 의미 | 조치 |
|------|------|------|
| **A. 의도된 위계** | 카드=목록 내 보조 버튼, 상세 footer=풀폭 주 CTA. 크기 차이가 정상 | **조치 없음**(⏹️ 종결). BACKLOG에 "의도된 위계로 확정" 기록 |
| **B. 괴리 = 단일화** | 같은 액션은 같은 크기여야 함 | footer를 `lg`→`md` 한 단계 낮춤(터치 타깃 유지). 카드 `sm`은 목록 밀도상 유지 |

> **시각 회귀 정책**: 토큰 값 변경 금지, **한 단계 위/아래로만** 조정. B 선택 시 footer `lg`→`md`(한 단계), 카드 `sm` 유지가 정책 부합. 카드를 올리는 방향은 목록 밀도 해쳐 비권장.

### 권장 흐름
착수 세션 도입부에서 A/B를 사용자에게 제시 → 확정 후 진행. A면 코드 변경 0, B면 아래 T1~T3.

---

## 3. 아토믹 태스크 (B 선택 시)

### T1 — footer 주 CTA 크기 조정
- 상세 footer 3버튼(준비 시작·택배 발송 완료·강제 취소) `size="lg"`→`size="md"`로 한 단계 하향. `radius="xl"` 유지 여부는 육안 비교 후 결정(괴리 핵심은 size).
- 풀폭(`fullWidth`)은 유지 — 터치 타깃 확보.

### T2 — 카드 버튼 정합 확인
- 카드 `size="sm"`은 목록 밀도상 유지. footer 하향으로 2단계→1단계 차로 괴리 완화.

### T3 — 정합성 + 빌드
- 셀러 `tsc --noEmit`·`next build` exit0, biome 신규 0.
- 육안: 카드→상세 이동 시 크기 점프 완화 확인.

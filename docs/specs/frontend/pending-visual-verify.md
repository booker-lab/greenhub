# 과거 미검증 육안 검증 통합 기록

> **원 통합일**: 2026-05-25 이후
> **상태**: 역사 자료 / 현재 실행 체크리스트 아님
> **최종 정합화**: 2026-08-23 KST

## 목적

이 문서는 과거 seller/admin UI 리팩터링 뒤 브라우저 육안 확인이 남았던 항목을 합쳐 둔 기록이다.

당시 포함 범위:

- 정산 status 필터 UI
- 버튼 크기 단일화
- admin 테이블 모바일 반응형
- admin+seller 겸직 역할 화면
- 수수료 입력 UI 등

과거 문서의 미체크 `[ ]` 항목은 **현재 미완료 제품 backlog를 뜻하지 않는다**. 현재 UI가 여러 차례 변경됐기 때문에, 필요하면 현재 코드와 현재 요구사항으로 새 visual verification Task를 만든다.

## 실행 금지된 과거 절차

과거 버전에는 운영 DB를 대상으로 visual seed를 만들거나 혼합 status 데이터를 준비하는 예시가 있었다. 이 절차를 현재 그대로 실행하지 않는다.

특히 문서 정합성 작업이나 read-only UI 감사에서 다음을 하지 않는다.

- production Firestore에 visual/reset/e2e seed 추가
- 운영 주문·정산 상태 변경
- 과거 seed script를 현재 환경 확인 없이 실행
- 과거 계정·스토어·URL을 현재값으로 가정

운영 데이터 변경이 필요한 시각 검증은 별도 Task와 사용자 승인, 격리 데이터 설계가 먼저다.

## 현재 검증 방법

특정 UI를 다시 확인해야 하면:

1. 현재 `main`의 화면 코드를 확인한다.
2. 현재 API/domain spec과 shared type을 확인한다.
3. 기존 E2E fixture 또는 비운영 Preview 데이터로 재현 가능한지 먼저 본다.
4. 필요한 Acceptance Criteria만 새 체크리스트로 만든다.
5. production 데이터 변경 없이 가능한 검증을 우선한다.

## 역사적 가치

Git history의 이전 본문은 2026-05 당시 어떤 UI 항목이 수동 육안 확인 대상으로 남았는지 추적할 때 사용할 수 있다. 당시 체크박스와 seed 지시는 현재 출시 판단이나 현재 실행 명령으로 사용하지 않는다.

# §3. 겸직 계정(admin+seller) 역할 분리 (세션89 #CL-52)

> 배경: "어드민=store 없음" 전제로 만들어진 `proxy.ts` 가드가 겸직 계정(어드민 + 디어 오키드 판매자)의 사업자 프로필 수정을 막던 결함.

> 노출 판정 SSOT = `role==='admin' && !!storeId`. 로그인 수단 무관.
> **계정 3종 교차 확인 필수**: 겸직(당신) / 일반 셀러 / (가능 시) 순수 어드민.

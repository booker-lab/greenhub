- **서비스**: 그린러브

- **적용 범위**: consumer 웹과 consumer가 호출하는 GreenLove API의 현재 구현
- **제외 범위**: 회원 탈퇴 API, 카카오 연결 해제 웹훅, 자동 보존기간 만료 삭제, 외부 배송 수행자 도입, 실제 provider 발송·결제·환불 및 production 활성화

이 문서는 공개 페이지 구현의 단일 정본이다. 화면 문구는 이 문서의 현재 사실과 금지 문구를 벗어나지 않아야 한다. 법령·인프라·처리 흐름 또는 판매 운영 상태가 바뀌면 공개 문서의 시행일과 이전 버전을 함께 관리한다.

## 확인 근거

### 코드와 운영 상태

- 카카오 로그인은 카카오 계정 식별자, 이름, 이메일을 consumer Auth.js에서 API로 전달한다.
- API는 회원 프로필, 주소록, 주문 시도, 결제 시도, 알림, 감사 로그와 갱신 토큰을 Firestore에 저장할 수 있다.
- 장바구니 `greenhub_cart`, 체크아웃 전달값 `checkout_cart`, 알림 읽음 상태 `gh_read_notifications`는 이용자의 브라우저 저장소에 저장된다.
- Auth.js는 로그인 세션과 OAuth 안전성 확인을 위한 필수 쿠키를 사용한다. 현재 구성의 세션 기본 유효기간은 최종 사용 후 30일이고 OAuth PKCE·state 쿠키는 15분이다.
- consumer에는 별도 광고·행태 분석 쿠키나 자동화된 의사결정 기능이 없다. 현재 파일럿에서는 선택 마케팅 동의를 수집하거나 마케팅 발송을 운영하지 않으며, 과거에 이미 저장된 마케팅 선호·동의 기록은 삭제하지 않는다.
- consumer에는 회원 탈퇴 화면·API와 카카오 연결 해제 웹훅이 없고, API의 일반 개인정보 컬렉션에는 자동 만료 삭제가 없다. 이용자 권리 요청은 고객센터가 접수해 운영자가 수동 처리한다.
- Firestore 기본 데이터베이스는 서울(`asia-northeast3`)에 있다. API는 Railway 미국 캘리포니아 리전(`us-west2`)에서 실행된다. consumer 프런트엔드는 Vercel에서 제공된다.
- 현재 통제된 공개 파일럿의 회차 직배송 주문은 PortOne을 통한 결제 요청·원격 상태 확인·환불 경로와 거래성 주문 알림 경로를 사용한다. PortOne은 결제 연동·상태 확인·환불 요청의 기술 경로이고 실제 결제사업자(PG·간편결제 사업자)는 결제 화면과 계약에 따라 정해진다.
- 주문 요청 시 `LEGAL_ORDER` 보존 기록에 `CONTRACT`·`SUPPLY` 유형이 남을 수 있다. 이는 주문 요청과
  공급 관련 증거의 보존을 위한 내부 기록이며, 이용자에게 주문이 확정되었다고 알리는 customer-facing
  주문 접수는 결제 상태·금액 확인 뒤 `ACCEPTED`로 전환되는 현재 lifecycle을 따른다.
- 회차 직배송은 경기도 이천시 배송지와 화면에 표시된 회차·일정 범위에서 제공한다. 판매자·배송 담당자는 현재 디어 오키드 내부 운영 인력이다.
- 주문 상태 알림은 선택 마케팅과 별개인 거래성 알림이다. 현재 코드의 ALIGO 경로는 거래성 카카오 알림톡·SMS 전달을 담당하며, 실제 provider 발송은 별도 운영 승인과 설정에 따른다.

### 4. 제3자 제공

회사는 이용자의 개인정보를 위 목적 범위에서 처리하고, 동의 또는 법률상 근거 없이 외부 제3자에게 제공하지 않는다. 파일럿에서는 디어 오키드 내부 판매 담당자 1명과 디어 오키드 MVP 사용자 본인인 배송 담당자 1명이 업무상 필요한 최소 범위에서 접근한다. 판매 담당자는 자기 매장의 주문을 인증된 서버 조회와 최소화된 projection으로 처리하고, 배송 담당자는 배정되었거나 배송을 위해 공개된 회차 주문의 이름·주소·상품·상태와 단계별 연락정보를 처리한다. 원문 주문 전체나 마케팅 정보에 임의로 접근하지 않는다. 관리자는 환불·주문·배송·정산 등 운영에 필요한 권한 범위에서 접근한다.

향후 적법하게 외부 배송 수행자를 지정하는 경우에는 배송 수행에 필요한 정보만 처리하게 하고, 수령자·목적·항목·보유기간 및 필요한 국외 처리 내용을 실제 도입 전에 방침과 거래 화면에 추가한다. 현재 존재하지 않는 외부 배송업체나 위탁관계를 현재 사실로 표시하지 않는다.

국외 처리 국가와 하위처리자는 각 사업자의 공식 하위처리자 목록에서 확인할 수 있도록 링크를 제공한다. 이용자는 고객센터에 국외 처리 중단을 요청할 수 있다. 중단이 기술적으로 어려운 경우 회원 로그인·주소록·주문 관련 기능 이용이 제한될 수 있으나 로그인하지 않은 공개 콘텐츠는 이용할 수 있다.

### 7. 쿠키와 브라우저 저장소

- 필수 인증 쿠키: Auth.js 로그인 세션, CSRF, callback URL, PKCE, state 등 로그인 유지와 요청 위조 방지에 필요한 쿠키를 사용한다.
- 기본 유효기간: 로그인 세션은 마지막 사용 후 최대 30일이고, PKCE·state 등 일회성 OAuth 쿠키는 최대 15분이며 완료 후 만료된다.
- 브라우저 저장소: 장바구니와 알림 읽음 상태는 `localStorage`, 체크아웃 전달값은 `sessionStorage`를 사용한다.
- 거부 방법: 브라우저 설정에서 쿠키와 사이트 데이터를 삭제하거나 차단할 수 있다. 필수 쿠키를 차단하면 로그인과 회원 기능이 동작하지 않을 수 있다.
- 현재 광고·행태 분석·마케팅 목적 쿠키는 사용하지 않는다.

### 8. 이용자 권리와 행사 방법

이용자는 개인정보 열람, 정정·삭제, 처리정지, 동의 철회와 카카오 연결 해제를 요청할 수 있다. `support@greenlove.co.kr` 또는 `010-4452-2104`로 본인 확인에 필요한 최소 정보를 보내면 운영자가 지체 없이 확인하고 결과를 안내한다. 자동 회원 탈퇴와 카카오 연결 해제 웹훅은 아직 없으므로 해당 기능이 있다고 표현하지 않는다. 운영자는 삭제 전에 법정 보존정보를 분리하고 카카오 개발자 도구 또는 API에서 필요한 연결 해제 조치를 수행해야 한다.

### 9. 안전성 확보조치와 구제

권한 최소화, 인증정보 보호, 전송구간 암호화, 접속·감사 기록, 정기 업데이트와 위탁사 점검을 안전조치로 설명한다. 침해 신고·분쟁조정 안내에는 개인정보침해 신고센터 `privacy.kisa.or.kr / 118`, 개인정보분쟁조정위원회 `kopico.go.kr / 1833-6972`를 제공한다. 기관 정보가 바뀔 수 있으므로 배포 전 공식 페이지를 재확인한다.

### 10. 변경과 이전 버전

시행일과 변경 공지 원칙을 마지막에 표시한다. 중요한 변경은 시행 전에 사이트에서 알리고, 이전 방침을 이용자가 확인할 수 있는 보관 경로를 마련한다. 이번 개정 전 공개본의 시행일은 `2026-08-19`이다.

## 이용약관 공개 문안 계약

### 1. 목적·운영자·용어

약관은 디어 오키드가 운영하는 그린러브 consumer 웹의 이용 조건과 회사·이용자의 권리와 책임을 정한다. `회원`, `이용자`, `상품정보`, `장바구니`, `판매기능`을 정의한다. 현재 파일럿의 판매기능은 화면에 표시된 회차·지역·일정 범위에 한정한다.

### 2. 현재 제공 범위

현재 서비스는 공개 상품·사업자 정보 열람, 카카오 로그인, 회원 프로필·주소록, 장바구니와 통제된 공개 파일럿의 회차 주문·결제·이천시 직배송을 제공한다. 모든 상품·지역·배송방법이 판매되는 것은 아니며 상품 표시나 장바구니 담기만으로 매매계약이 성립하지 않는다.

### 3. 약관 효력과 변경

약관은 서비스 화면에 게시한 시행일부터 적용한다. 회사는 관계 법령을 위반하지 않는 범위에서 변경할 수 있고 적용일·변경 이유·주요 내용을 시행 전에 알린다. 이용자에게 불리한 중요한 변경은 합리적인 사전 고지기간을 둔다.

### 4. 계정과 이용자 의무

이용자는 카카오 로그인을 통해 계정을 사용할 수 있고 정확한 정보를 제공해야 한다. 계정·기기 관리를 다하며 타인의 정보 사용, 서비스 방해, 불법 이용, 콘텐츠·시스템 권리 침해를 해서는 안 된다. 이상 사용·보안 위험·법령 위반이 있으면 회사는 필요한 범위에서 이용을 제한하고 사유를 안내할 수 있다.

### 5. 서비스 변경·중단

점검, 장애, 천재지변, 통신망·외부 서비스 문제 또는 운영상 필요가 있으면 서비스를 변경하거나 일시 중단할 수 있다. 예측 가능한 경우 사전에, 긴급한 경우 사후에 알린다. 회사의 고의 또는 과실에 따른 법정 책임을 일률적으로 배제하지 않는다.

### 6. 파일럿 주문 성립·승낙·공급

이용자가 주문을 요청하면 결제 확인 전 대기 상태가 생성될 수 있다. 회사는 PortOne을 통해 결제사업자(PG·간편결제 사업자)의 결제 상태와 금액을 서버에서 확인한 뒤 주문을 접수하고, 정상 확인된 주문을 `ACCEPTED` 주문 접수 상태로 전환하여 `ORDER_ACCEPTED` 거래성 알림을 보낸다. 결제 요청·대기·실패·금액 불일치만으로 주문 접수나 재화 공급이 확정되지 않는다.

- 판매자 측 운영자는 주문 접수 후 상품을 준비하고, 담당 배송 인력이 배송 상태를 처리한다.
- 현재 파일럿은 화면에 표시된 회차·경기도 이천시 배송지·배송일정 범위에서 직접배송으로 운영한다.
- 주문·결제·배송에 필요한 거래성 안내는 선택 마케팅 수신 동의와 별개로 제공한다.

판매자 측 운영자의 준비 업무가 별도의 수동 승인 버튼을 의미하는 것은 아니다. 이 문서의 주문 접수·승낙은 결제 확인과 회사의 주문 수락 처리를 함께 가리킨다.

### 7. 소비자 취소·운영상 취소·환급

소비자는 자신의 회차 주문을 해당 회차의 주문 마감 전이고 시스템이 허용하는 상태일 때 취소할 수 있다. 마감 후 또는 배송이 진행된 후에는 소비자 화면에서 직접 취소가 제한될 수 있고, 고객센터가 주문 상태와 처리 가능 여부를 확인한다.

결제 전 취소는 예약·회차 용량 반환 후 주문을 취소로 정리한다. 결제가 확인된 주문은 회사가 PortOne·결제사업자의 환불 경로를 통해 환불을 요청하고 주문·결제·정산 상태를 정리한다. 외부 결제사업자 응답이나 운영 오류가 있으면 즉시 환불·취소가 완료되지 않고 확인·재처리 상태로 남을 수 있다.

판매자 또는 회사의 권한 있는 운영자는 재고·품질·배송·결제 오류 등 운영상 사유로 허용된 주문 상태를 취소할 수 있다. 정상 취소 경로에서는 사유를 기록하고 결제 환불, 예약·회차 용량 반환과 정산 취소를 현재 상태에 맞춰 처리한다. 관리자 강제 환불 등 예외 경로는 주문·결제·정산 상태를 별도로 확인해 처리한다. 청약철회·반품·환급은 전자상거래법 등 강행규정에 따르며 소비자의 법정 권리를 일률적으로 제한하지 않는다. 신선화훼의 가치 감소나 소비자 책임에 따른 제한은 거래 전에 상품별 사유와 방법을 안내한다.

### 8. 배송 보류와 고객 책임 재배송비

파일럿 배송은 회차 화면에 표시된 배송 일정과 배송지 범위에 따라 준비 후 진행한다. 기상, 출입 불가, 주소 문제, 수령인 연락 불가 등으로 배송할 수 없으면 주문을 임의 완료하지 않고 `DELIVERY_HELD` 배송 보류로 기록하며, 보류 사유와 다음 연락·배송 예정 시각을 안내한다. 기상 등 회사 또는 운영상 사유에는 고객 책임 재배송비를 부과하지 않는다.

고객 책임으로 첫 배송이 실패하고 양수의 재배송비가 정해지면 주문자 본인에게 본 주문과 별도의 `REDELIVERY_FEE` 결제를 요청할 수 있다. 같은 보류에 중복 청구하지 않으며, 결제사업자의 결제 상태가 `PAID`로 확인되기 전에는 유료 재배송을 시작하지 않는다. 결제 실패·연결 불일치·운영 확인이 필요한 경우 배송은 보류되고 자동 재개되지 않는다.

배송 완료는 담당 배송 인력이 필요한 배송 기록을 남기고 서버가 `DELIVERED`로 처리한 때 기록한다.

### 8. 개인정보·지식재산권·면책

개인정보 처리는 별도 개인정보처리방침을 따르고 약관에서 상호 링크한다. 회사 또는 권리자에게 귀속되는 콘텐츠를 허가 없이 복제·배포하지 않는다. 불가항력이나 이용자 귀책사유에 대한 합리적 범위를 설명할 수 있으나 회사의 고의·중과실 또는 법률상 책임까지 면제하지 않는다.

### 9. 준거법·분쟁과 문의

대한민국 법률을 준거법으로 하며 분쟁은 당사자 간 협의를 우선한다. 해결되지 않으면 민사소송법 등 관계 법령이 정한 관할법원에 따른다. 고객센터 이메일·전화·상담시간을 약관 마지막에 표시한다.

## 공개 페이지 공통 계약

- 두 경로는 로그인 없이 HTTP 200으로 열리고 `metadata`에 각각 명확한 한국어 제목과 설명을 둔다.
- 공통 Server Component 셸은 브랜드 홈 링크, 문서 제목, 시행일, 운영자, 읽기 쉬운 본문 폭과 모바일 하단 내비게이션을 피하는 여백을 제공한다.
- 개인정보처리방침과 이용약관은 본문 상단 또는 하단에서 서로 이동할 수 있어야 한다.
- 홈 사업자 정보 footer에는 `개인정보처리방침`, `이용약관` 링크를 충분한 터치 영역으로 표시한다.
- 문서에는 현재 존재하지 않는 외부 배송업체·위탁관계·국외 이전을 현재 사실처럼 추가하지 않으며, 통신판매업 신고번호 등 별도 사업자 고지는 실제 법률·운영 확인 뒤 반영한다.

## 운영 위험과 후속 의무

1. 회원 탈퇴 API·화면, 카카오 연결 해제 웹훅, 일반 데이터 자동 보존기간 만료 삭제를 별도 API 계획으로 구현해야 한다.
2. 현재 Vercel Hobby 계정은 공개 Vercel DPA의 적용 대상이 아니므로 개인정보 처리 규모 확대 전 계약·요금제와 적법한 국외 처리 근거를 법률·운영 관점에서 재검토해야 한다.
3. Railway 미국 API 리전에 회원·주문 관련 요청이 전달되므로 공개 방침과 실제 배포 리전의 일치를 릴리스마다 확인해야 한다.
4. 외부 판매자·배송업체·택배사 또는 다른 마케팅 메시지 공급자를 실제 사용하기 전에는 제공·위탁·국외 처리 표와 고지를 갱신해야 한다. PortOne·PG·ALIGO의 계약·활성 범위가 바뀌는 경우에도 같은 원칙을 적용한다.
5. 파일럿 범위를 넘어 판매기능을 확대하기 전 통신판매업 신고 여부와 전자상거래법상 사업자 표시, 공급·청약철회·비용 부담 기준을 별도 승인으로 확정해야 한다.
6. 공개 후 과거 버전 보관과 개정 공지 절차를 운영한다.

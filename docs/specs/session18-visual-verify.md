1. 브라우저 DevTools 콘솔 열기 (F12 → Console)

## ① Firebase 429 Rate-Limit Fix

**확인 위치**: DevTools Console → 로그인 직후

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| 로그인 직후 Console에 `429 Too Many Requests` 에러 없음 | ✅ 에러 없음 |
| `firebase.google.com` 호출이 1회만 발생 | Network 탭에서 `identitytoolkit` 호출 중복 없음 |
| 홈 대시보드 정상 렌더링 | 실시간 데이터 표시됨 |

---

## ② G2 — 주문 상세 상품명 표시

**확인 위치**: `/orders` → 주문 카드 클릭 → `/orders/[id]`

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| 상품정보 라벨이 **"상품명"** 으로 표시 | "상품 ID" 텍스트가 없음 |
| 상품명에 실제 상품명이 표시 (예: "스카비오사 다발 20본") | raw Firebase ID가 아닌 이름 |
| 상품명 없는 주문 — fallback으로 상품 ID 표시 | ID라도 표시됨 (빈 칸 아님) |

---

## ③ preparedAt — 빠른 선택 UI

**확인 위치**: `/orders/[id]` → **"준비 시작"** 버튼 클릭

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| 버튼 클릭 시 빠른 선택지 3개 출현 | "오늘 오후 2시", "오늘 오후 4시", "내일 오전 9시" |
| 선택지 클릭 시 "선택됨: OOO" 텍스트 표시 | 파란 테두리 + 선택됨 텍스트 |
| 동일 선택지 재클릭 시 선택 해제 | "준비 완료 예정 시각을 선택하세요" 안내문 복원 |
| 선택지 클릭 후 "준비 시작" 제출 버튼 활성화 | 버튼 클릭 가능 상태 |

---

## ④ B1 — 온보딩 폼 Pre-fill

**확인 위치**: `/onboarding` (로그인 상태에서 접근)

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| `/onboarding` 직접 접근 가능 | `/orders`로 리디렉트되지 않음 |
| 페이지 진입 약 1~2초 후 상호명 필드에 값 자동 입력 | 기존 상호명이 pre-fill됨 |
| 대표자명·연락처·소재지 필드도 자동 채워짐 | 기존 저장 데이터 반영 |
| 로고 미리보기 — 기존 로고 이미지 표시 | 로고 업로드 영역에 기존 이미지 |
| 필드 수정 후 저장 가능 | 폼 편집 + 제출 정상 동작 |

---

## ⑤ B2 — 상품 토글·삭제 에러 피드백

**확인 위치**: `/products` → 상품 카드

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| 상품 카드에 "판매 중" 또는 "비활성" 뱃지 표시 | 상태 뱃지 정상 렌더링 |
| 상품 카드에 "수정", "삭제" 버튼 표시 | 액션 버튼 2개 노출 |
| 토글 클릭 시 상태 변경 성공 | 뱃지 텍스트 변경 (비활성 ↔ 판매 중) |
| 토글/삭제 실패 시 카드 내 에러 텍스트 표시 | 네트워크 끊고 테스트 (선택적) |

---

## ⑥ G3 — 일별 정산 날짜 선택기

**확인 위치**: `/settlements` → **"일별 요약"** 탭

| 확인 항목 | 예상 결과 |
|-----------|-----------|
| 일별 요약 탭에 날짜 선택기(`<input type="date">`) 존재 | 날짜 입력 UI 표시 |
| 날짜 선택기 최대값이 오늘 이하 | 미래 날짜 선택 불가 |
| 날짜 변경 시 헤더 날짜 레이블 갱신 | "2026년 5월 9일" 형식으로 업데이트 |
| 날짜 변경 후 해당 날짜 데이터 자동 조회 | 스피너 → 정산 데이터 갱신 |
| 기간별 조회·주문별 상세 탭은 날짜 선택기 없음 | 일별 탭 전용 UI |

---

## 전체 플로우 빠른 확인 순서

```
1. 로그인 → Console 에러 없음 확인 (① Firebase)
2. / (홈) → 대시보드 정상 렌더링
3. /orders → 주문 클릭 → 상품명 확인 (② G2)
4. /orders/[id] → 준비 시작 → 선택지 3개 확인 (③ preparedAt)
5. /onboarding → pre-fill 확인 (④ B1)
6. /products → 상품 카드 뱃지·버튼 확인 (⑤ B2)
7. /settlements → 일별 탭 날짜 선택기 확인 (⑥ G3)
```

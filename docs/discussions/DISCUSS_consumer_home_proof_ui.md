# DISCUSS: consumer 홈페이지 증빙 UI 정돈

## 1. 현황 요약

- **이번 discuss에서 끝까지:** 카카오 심사 증거를 유지하면서 그린러브 홈페이지를 정상적인 화훼 쇼핑몰처럼 보이게 개선할 범위와 완료 기준을 확정한다.
- 현재 홈 상단의 운영 안내가 사업자 정보와 대표상품 링크를 한 카드에 모두 담아 쇼핑 흐름보다 소명자료처럼 보인다.
- 같은 사업자 관계가 상단과 footer에서 반복되고, 텍스트형 대표상품 목록이 실제 상품 카드와 시각적으로 분리돼 있다.
- 운영 상품 목록의 시험용 상품과 이미지 미노출도 전체 완성도를 낮추지만 운영 데이터 정리는 화면 개편과 권한 범위를 분리해야 한다.
- 향후 consumer 프론트엔드를 대대적으로 개편할 예정이므로 이번 작업은 미래 디자인을 미리 확정하거나 광범위한 공통화를 만들지 않아야 한다.

## 2. 진행 중 결정 (누적)

- [확정] 균형형 구조를 채택한다. — 상단 안내를 축소하면서 정적 상품 증거와 footer 정본을 유지한다.
- [확정] 정적 대표상품 3개는 간결한 상품 타일로 표시한다. — 가격·이미지 중복 없이 상품명과 상세 이동 경로를 안정적으로 유지한다.
- [확정] 향후 대대적인 프론트엔드 개편을 별도 작업으로 진행한다. — 이번 심사 증빙 정돈이 미래 전체 디자인을 선점하지 않는다.
- [확정] 이번 작업은 교체하기 쉬운 소규모 구성으로 정돈한다. — 임시 시각 보정에 그치지 않되 미래 디자인 기반은 선행하지 않는다.
- [확정] 이번 범위는 카카오 심사를 위한 증빙 화면 정돈으로 제한한다. — 시험용 상품·이미지 데이터 정리는 향후 전체 프론트엔드 작업으로 넘긴다.
- [확정] 실제 상품 목록이 비거나 불러오기에 실패해도 운영 안내와 정적 대표상품 타일을 유지한다. — 심사 증거가 운영 데이터 상태에 좌우되지 않게 한다.
- [확정] 모바일과 데스크톱 모두에서 증빙 확인과 쇼핑 흐름을 확인한다. — 운영 관계·공식 채널·대표상품이 쉽게 보이고, 가로 넘침 없이 쇼핑 화면을 과도하게 점유하지 않아야 한다.
- [확정] 상단 증빙 구획은 “그린러브는 디어 오키드가 운영하는 화훼 쇼핑몰입니다.”를 핵심 문장으로 둔다. — 사업자와 채널·쇼핑몰의 관계를 심사자가 즉시 확인하게 한다.

## 3. 합의된 방향 · 범위

- 방향: 상단은 간결한 운영 안내로 줄이고 정적 대표상품 증거는 간결한 타일로 유지하되 향후 전체 개편과 결합하지 않는다.
- 이번에 하는 것: “그린러브는 디어 오키드가 운영하는 화훼 쇼핑몰입니다.”를 상단 핵심 문장으로 두고, 공식 카카오 채널 링크, 정적 대표상품 타일 3개, footer 상세 사업자정보의 역할을 분리한다.
- 안 하는 것: 비공개 사업자정보 공개, 카카오 심사 제출 내용 변경, 시험용 운영 상품 삭제, 이미지 데이터 정리, 데이터·API 변경, 판매·주문 로직 변경, 전체 프론트엔드 개편
- 완료 기준: 모바일·데스크톱에서 운영 관계, 공식 카카오 채널, 대표상품 타일 3개를 쉽게 확인할 수 있고 가로 넘침이 없으며, 증빙 구획이 일반 상품 탐색을 과도하게 방해하지 않는다.
- 엣지 케이스: 실제 상품 목록이 비거나 불러오기에 실패해도 운영 안내, 공식 채널 링크, 정적 대표상품 타일 3개는 노출한다.
